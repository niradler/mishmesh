The figures are functional test observations, not sizing benchmarks. Test-only certificates skip verification. The compose stack uses isolated test credentials and only publishes the API on loopback.

## Confirmed causes and fixes

- Long-poll: fixed ResponseHeaderTimeout was two minutes. MISHMESH_UPSTREAM_RESPONSE_TIMEOUT is now wired to ingress and Helm, defaults to 5m, and rejects invalid/nonpositive values at startup.
- gRPC HTTP ingress: original transport sent HTTP/1.1. Standard gRPC media types now select an HTTP/2 transport; agent stream metadata requests ALPN h2 for HTTPS targets. Plaintext ingress accepts h2c. Tests cover endpoint isolation, trailers, header timeout, and ALPN support/rejection.

## Release follow-up changes

- Path-routing state now reaches gateway bindings, control API URLs, and SSH forward URL construction. When disabled, path URLs are empty and host/TCP URLs remain usable.
- Helm values expose path routing, allowed origins, private proxy policy/CIDRs, and organizations-per-user cap. Focused tests and server compilation pass. All three Helm profiles lint, and `../verify-helm-security.py` validates rendered defaults and overrides.
- Full `make check` passed after all production code changes. Runtime proof of disabled path URLs passed: all nine endpoint API URLs and the agent banner exclude path URLs in the cluster stack. Helm render checks are included in CI.
