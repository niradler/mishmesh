The figures are functional test observations, not sizing benchmarks. Test-only certificates skip verification. The compose stack uses isolated test credentials and only publishes the API on loopback.

## Confirmed causes and pending direction

- Long-poll: ingress defaults ResponseHeaderTimeout to two minutes. UpstreamResponseTimeout exists in ingress options but is not wired through the server config. Direction requested: expose a duration setting with the current default, or document the fixed beta limit.
- gRPC HTTP ingress: the upstream http.Transport uses HTTP/1.1. Direct and TCP controls pass. Direction requested: document TCP/TLS alternatives for beta, or add HTTP/2 upstream support.

## Release follow-up changes

- Path-routing state now reaches gateway bindings, control API URLs, and SSH forward URL construction. When disabled, path URLs are empty and host/TCP URLs remain usable.
- Helm values expose path routing, allowed origins, private proxy policy/CIDRs, and organizations-per-user cap. Focused tests and server compilation pass. All three Helm profiles lint, and `../verify-helm-security.py` validates rendered defaults and overrides.
- Full `make check` passed after all production code changes. Runtime proof of disabled path URLs passed: all nine endpoint API URLs and the agent banner exclude path URLs in the cluster stack. Helm render checks are included in CI.

## New issues found during validation

- A fresh vulnerability scan found 10 reachable vulnerabilities in Go 1.26.6, fixed by raising the minimum and Docker builder version to Go 1.26.9 and x/net to v0.60.0. Both main and kit govulncheck now pass with zero reachable vulnerabilities. Main has one module-only advisory for unused OpenPGP packages (GO-2026-5932, no fixed version). `go list -deps ./...` confirms OpenPGP is not imported.
- Fresh simultaneous cluster startup failed on duplicate `ag_bootstrap` creation. EnsureBootstrap now rereads and validates the concurrent winner for agent and token inserts. Deterministic concurrent regression passed ten times with the race detector; both pods then started against fresh PostgreSQL with exactly one agent and one token.
- The fresh PostgreSQL fixture initially reused the old Redis namespace, so stale port claims stopped the agent. A fresh Redis DB 1 namespace paired with the fresh PostgreSQL database resolved this fixture mismatch without deleting state.
- Web build and production npm audit passed (zero vulnerabilities). Existing Vite bundle warning: 510.63 kB minified JS. The test agent also prints the TLS passthrough endpoint with the public HTTP scheme; the tested passthrough connection uses its actual TLS listener, not that banner URL. These are follow-up issues outside the current fixes.
