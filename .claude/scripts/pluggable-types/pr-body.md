Apps can use named Cloudflare public connections and Tailscale private HTTPS connections over existing networks. Typed service and connection APIs, descriptor-driven UI and per-endpoint Access refs replace the fixed service spec/singleton Cloudflare model. Startup atomically migrates legacy schemas, connection ciphertext/AAD, endpoint refs and parsed Cedar actions using one preloaded matching key. Missing/wrong keys and malformed records fail without partial conversion. Backup and restoration require the matching pre-migration database/key pair. No Kubernetes provider or VPN peer/key/route management is included.
